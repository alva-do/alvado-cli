# alvado CLI

Binaires de la CLI `alvado`, l'outil en ligne de commande du CRM alva.do.
Le code source est privé ; ce dépôt ne contient que les releases.

## Installation

```sh
curl -fsSL https://www.alvado.fr/install.sh | sh
```

Ou avec Homebrew : `brew install alva-do/tap/alvado`.

Puis : `alvado login`.
